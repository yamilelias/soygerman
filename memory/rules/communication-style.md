# Estilo

Un solo tema: cómo escribir en este proyecto.

- Con la persona: español, frases completas, primero el resultado.
- Interfaz, README y mensajes de commit: español. El commit dice por qué, en una o dos frases.
- Tono interno: directo. Tono de la app: claro y breve, como las pantallas ya escritas («Entrar», «Revisa tu correo»).
- Fechas visibles para quien usa la app: `es-MX`.
- No inventes un nombre de persona a partir del usuario de GitHub.
